
# 🚀 DevBlog — Frontend Developer Blog

Особистий блог веброзробника, присвячений HTML, CSS та JavaScript. Місце, де я ділюся своїм досвідом навчання, практичними прикладами, корисними порадами та відкриттями у світі Frontend-розробки.

📌 Про проєкт

DevBlog — це персональний блог-портфоліо, створений для демонстрації моїх навичок у Frontend-розробці та публікації технічних статей.

Головна мета проєкту — ділитися реальним досвідом навчання та показувати свій прогрес у веброзробці.

✨ Основні можливості

- 🏠 Головна сторінка — коротка інформація про розробника.
- 📝 Статті — публікації про HTML, CSS, JavaScript та інші технології.
- 💻 Блок About Me — інформація про розробника у стилі термінала.
- 🛠️ Навички — секція для демонстрації технічних навичок.
- 📩 Контакти — можливість зв'язатися зі мною.
- 📱 Адаптивний дизайн — підтримка різних розмірів екранів.

🛠️ Технології

Проєкт створений з використанням:

- HTML5 — структура та семантична розмітка сторінки.
- CSS3 — стилізація, анімації та адаптивний дизайн.
- JavaScript — інтерактивність та динамічна поведінка елементів.
- Google Fonts — шрифти Inter та JetBrains Mono.

📂 Структура проєкту

```text
devblog/
│
├── index.html
├── script.js
│
└── css/
    └── styles.css
```

🚀 Як запустити проєкт

1. Клонуйте репозиторій:

   ```bash
   git clone https://https://github.com/yuriigeek2014-hue/devblog
   ```

2. Перейдіть до папки проєкту:

   ```bash
   cd DevBlog
   ```

3. Відкрийте файл `index.html` у браузері.

Також можна скористатися розширенням Live Server у Visual Studio Code для локального запуску проєкту.
